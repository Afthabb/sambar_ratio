IMPORTANT TECHNICAL REQUIREMENTS

==================================================

Use React + Vite.

Use Tailwind CSS if appropriate.

Use Lucide icons or another lightweight icon library.

Do not rely on external APIs for the core functionality.

The entire application must work offline after dependencies are installed.

Use local/static assets where possible.

Use placeholder images initially if required, but structure the project so they can easily be replaced.

Keep all calculations deterministic.

Store user selections in application state.

Make all screens responsive.

Desktop should be the primary presentation target, but mobile should still work.

Use reusable components for:

- GlassCard

- PillButton

- LoadingAnimation

- FoodCard

- MaterialCard

- MetricCard

- MixingSimulation

- ProgressIndicator

- ReportCard

IMPORTANT:

Do not build this as a boring form-based website.

The main purpose is visual impact and interactive entertainment.

The reference image's aesthetic should strongly influence the final design:

soft blurred background + glass panels + food photography + minimal typography + large rounded cards + floating decorative elements.
